# musk-x-digest（練習用サイト）

イーロン・マスク氏の X での発言を、AI（Grok Bot）が3時間おきに日本語で要約して自動で掲載する**練習用サイト**です。GitHub Pages（Jekyll）で公開しています。

- 練習用サイトです。
- レポートは AI（Grok）による自動生成です。内容の正確性は保証しません。
- 非公式。イーロン・マスク氏および X Corp. とは一切関係ありません。

## _posts のルール

Grok Bot はこのルールに従ってファイルを追加する。

- Grok Bot が触ってよいのは `_posts/` フォルダの中だけ。それ以外のファイルは変更しない
- ファイル名：`_posts/YYYY-MM-DD-HHMM-musk.md`（例：`_posts/2026-10-16-0800-musk.md`。時刻は日本時間）
- ファイルの先頭に次の情報を書く：

```
---
layout: post
title: "10/16 08:00 のまとめ"
date: 2026-10-16 08:00:00 +0900
---
```

- 本文の構成：
  1. `## 主な投稿`：投稿ごとに、要約（2〜3文）と投稿の URL
  2. `## 反響`：主な反応の傾向を2〜3文
  3. `## この時間帯のポイント`：全体のまとめを1〜2文
- 投稿の文章は長く引用せず、日本語で要約する

### 図表・写真用の追加情報（2026-10-15 追加）

ファイルの先頭に、次の `topic` と `posts` も書く。サイトがこの情報からグラフとイメージ写真を自動で表示する。

```
---
layout: post
title: "10/16 08:00 のまとめ"
date: 2026-10-16 08:00:00 +0900
topic: spacex
posts:
  - title: "Starship の次回打ち上げについて"
    topic: spacex
    url: "https://x.com/elonmusk/status/1234567890"
    views: 12000000
    likes: 85000
  - title: "新型車のソフトウェア更新について"
    topic: tesla
    url: "https://x.com/elonmusk/status/1234567891"
    views: 3400000
    likes: 21000
---
```

- `topic`：この回でいちばん多かったテーマ。次のどれか1つ
  - `tesla`（Tesla）／ `spacex`（SpaceX・Starlink）／ `ai`（xAI・Grok・AI 全般）／ `politics`（政治・社会）／ `other`（その他）
- `posts`：「主な投稿」に載せた投稿を、**同じ順番で**1件ずつ書く
  - `title`：投稿の内容を表す短い見出し（30文字以内）
  - `topic`：上と同じ5つから1つ
  - `url`：投稿の URL
  - `views`：表示回数、`likes`：いいね数。確認した時点のおおよその数を、**数字だけ**で書く（カンマや「万」は付けない）。確認できなければその行を書かない
- 値に `:` や `"` を含む見出しは、全体を `"` で囲む
